# Web Studio -> A1 integration contract

## A1 MCP tools

Web Studio calls typed A1 MCP tools only. It no longer writes to A1 tables through SQL.

Required tools:

- `crm_upsert_lead`
- `crm_move_lead_stage`
- `crm_add_event`
- `crm_convert_lead_to_deal`
- `deal_attach_product`
- `invoice_create_yookassa_link`
- `outbound_queue_message`
- `voice_call_queue` (must stay disabled for Web Studio v1)
- `crm_get_updates_since`

Lead identity:

- `externalId`: Web Studio lead id.
- `dedupeKey`: `webstudio:<leadId>`.
- `a1LeadId`: returned by A1 after upsert.
- `a1DealId`: returned by A1 after conversion to deal.

Stage mapping:

- Web Studio scout -> A1 `new`
- Web Studio diagnosis -> A1 `qualification`
- Web Studio Lovable/video -> A1 `in_work`
- Web Studio checker/offer -> A1 `offer`
- Web Studio outreach/reply -> A1 `follow_up`
- A1 deal conversion -> Web Studio reply/customer flow

## A1 -> Web Studio webhook

URL:

```text
https://webstudio.1true.ru/api/a1/webhook
```

Auth header:

```text
x-a1-webhook-secret: <A1_WEBHOOK_SECRET>
```

Optional idempotency header:

```text
x-idempotency-key: <stable-event-key>
```

Envelope:

```json
{
  "eventId": "a1_evt_...",
  "eventType": "lead.stage_changed",
  "occurredAt": "2026-05-06T12:00:00.000Z",
  "source": "a1",
  "entity": {
    "type": "lead",
    "a1LeadId": "uuid",
    "a1DealId": null,
    "externalId": "webstudio-lead-id",
    "dedupeKey": "webstudio:webstudio-lead-id"
  },
  "payload": {
    "stage": "qualification",
    "status": "in_progress",
    "text": "optional human-readable event text"
  }
}
```

Supported `eventType` values:

- `lead.stage_changed`
- `lead.replied`
- `lead.converted_to_deal`
- `deal.stage_changed`
- `deal.payment_link_created`
- `deal.payment_paid`
- `outbound.message_sent`
- `outbound.message_failed`
- `customer.telegram_started`
- `customer.brief_updated`
- `customer.revision_requested`

Unmatched events are stored in Web Studio `integrationInbox` and do not mutate leads.

## Telegram customer link

Outbound email should include:

```text
https://t.me/<TELEGRAM_BOT_USERNAME>?start=lead_<publicLeadToken>
```

The token is generated by Web Studio and sent in `webstudioLead.publicLeadToken` inside `crm_upsert_lead`.
